GEMINI 3.8 FLASH MULTI-ACCOUNT ROUTER

Halo! Saya adalah Gemini 3.8 Flash yang terhubung langsung melalui Pool Router Akun Google Anda.

Keunggulan sistem ini:

  • ⚡ Multi-Account Key Pool: Menghubungkan banyak akun Google/Gmail secara bersamaan.

CARA MENGHUBUNGKAN KE 9ROUTER & TOOLS LAIN

Gunakan proxy multi-akun Gemini ini sebagai penyedia model cerdas di 9router, Cursor, Claude Code, atau script otomatisasi Anda.

01

Integrasi ke 9router di VPS

Gunakan custom provider OpenAI di 9router

9router mendukung endpoint upstream berformat OpenAI. Arahkan base URL 9router ke proxy Gemini ini:

Endpoint Base URL
http://localhost:3003/v1
Nama Model untuk 9router
gemini-3.8-flash

API Key di 9router dapat diisi sembarang string (misal: gemini-pool-token) karena validasi dan rotasi key dilakukan otomatis oleh router ini.

02

Test Request via cURL

Standar OpenAI chat completion

Jalankan perintah ini di terminal untuk menguji multi-account failover langsung:

Bash / Terminal 
curl -X POST http://localhost:3003/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-3.8-flash",
    "messages": [
      {"role": "user", "content": "Jelaskan keunggulan Gemini 3.8 Flash dalam 2 kalimat."}
    ]
  }'
03

Python (OpenAI SDK)

Integrasikan ke agent / bot Python
Python 
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:3003/v1",
    api_key="gemini-pool-active"
)

response = client.chat.completions.create(
    model="gemini-3.8-flash",
    messages=[{"role": "user", "content": "Halo Gemini!"}]
)
print(response.choices[0].message.content)
04

Node.js / JavaScript

Untuk bot Discord, Telegram, dan web service
JavaScript 
import OpenAI from 'openai';

const openai = new OpenAI({
  baseURL: 'http://localhost:3003/v1',
  apiKey: 'gemini-pool-token'
});

const res = await openai.chat.completions.create({
  model: 'gemini-3.8-flash',
  messages: [{ role: 'user', content: 'Halo dari Node.js!' }]
});
console.log(res.choices[0].message.content);
